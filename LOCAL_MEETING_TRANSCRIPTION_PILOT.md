# Local council audio transcription (optional, offline)

This module adds **actual speech-to-text** for a council meeting recording that the operator has **already downloaded with permission**. It never downloads or streams the recording. It does not schedule collection or call any paid LLM.

## Prerequisites

- An existing Radar checkout and Python environment.
- Optional `faster-whisper` installed separately, and working `ffprobe`/FFmpeg available on the local PATH.
- A **previously downloaded CTranslate2 faster-whisper model directory** inside the Radar workspace. Do not use a model name such as `small` or `base`: the module refuses non-local directories and calls `WhisperModel(..., local_files_only=True)`, preventing model download.
- An authorized local recording in `.wav`, `.mp3`, `.m4a`, `.flac`, or `.ogg` format inside the workspace, no larger than 100 MB or 15 minutes. The operator can prepare a 15-minute excerpt separately if authorized. No audio/video extraction is performed by Radar.

Example (PowerShell, run from repository root):

```powershell
python gta_local_meeting_transcription.py --workspace "C:\Users\sande\Desktop\new data" --results "C:\Users\sande\Desktop\new data\GTA_RADAR_RESULTS" --audio "council_excerpt.wav" --local-model-dir "models\faster-whisper-small" --city Brampton --recording-url "https://www.brampton.ca/REPLACE_WITH_EXACT_MEETING_RECORDING" --authorized-local-transcription
```

Use the **exact official council recording URL** in place of the placeholder. The model and audio paths must refer to existing local workspace contents. The local model is loaded on CPU (int8) by default, to avoid requiring a GPU and to keep the CI/deployment simple. Optional dependencies are **not** added to the main `requirements.txt`, so the normal daily launcher remains unchanged.

Output:
- `GTA_RADAR_RESULTS/GTA_RADAR_LOCAL_TRANSCRIPTION_REVIEW.json`: source SHA256, review-only timestamped candidate mentions and transcript status.
- `GTA_RADAR_RESULTS/LOCAL_TRANSCRIPTS/<source-audio-sha256>.vtt`: timestamped WebVTT generated by offline speech recognition.

The generated VTT is checked by `gta_local_caption_evidence.parse_vtt` before it is saved. It is deliberately not added to the user-controlled `GTA_RADAR_MEDIA_INPUTS.json` manifest automatically. This avoids silently reprocessing historical transcripts as newly observed government disclosures. It can later be explicitly listed in the manifest if the file is moved into the workspace, or imported by an independently validated project-reconciliation stage.

**No source dates, approval events, project IDs or buyers are inferred.** ASR may mishear names, addresses, case numbers and dates. Original recording and official minutes remain authoritative evidence. This pilot has hermetic simulated transcription tests, **not** live municipal-audio acceptance. Local processing has not been benchmarked on the owner's hardware.

After testing on an authorized real recording, review the timecoded excerpts against audio and independently check whether they map to an existing planning application or a previously unseen real project. Only then consider promoting claims to Radar's verified project research queue.
