GTA RADAR EASY START - Windows SQLite fix

Fixes WinError 32 after database backup by closing both SQLite connections before renaming the temporary file.

HOW TO USE:
1. Close the previous failed black command window.
2. Extract this ZIP to your Desktop/new data folder.
3. When asked, replace files in GTA_RADAR_EASY_START (or extract in a separate folder and run there).
4. Double-click START_RADAR.bat.

Existing old Radar databases remain untouched.
If data/radar.sqlite.incomplete exists from the failed attempt, close all Radar/Python windows and delete ONLY that .incomplete file before running again.
