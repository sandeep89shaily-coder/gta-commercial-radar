# Focus reset: early investment cues only

This development mode runs **nine existing pilot runners (21 defined feeds, of
which 17 are additional to existing V8 definitions)**. It does not run the
ordinary municipal/permit collector, business collector, DeepSeek, or scheduled
tasks. The 14 disabled V8 collectors remain disabled and are not a workstream
until genuine pre-permit buying cues show value.

On Windows, extract the complete repository ZIP and double-click
`RUN_EARLY_ONLY.bat`. This keeps using the **isolated persistent preview**
database at `Desktop/new data/GTA_RADAR_V8_EARLY_PREVIEW`. No production
database is modified, and a source's initial baseline is not a new lead.

One focused output lives in
`GTA_RADAR_V8_EARLY_PREVIEW/GTA_RADAR_RESULTS/GTA_RADAR_EARLY_ONLY.html`.
The report distinguishes live post-baseline signals, qualified early research
candidates, source-level failures, and documents that require more evidence.
It never labels a prospect sale-ready because a public planning document exists.

The immediate priorities are fixing Brampton planning agenda extraction and
Burlington's incomplete ward snapshots; checking source-by-source successful
changes after baseline; and verifying buyer identity, procurement state, and
early timing for the first ten credible commercial projects. **Do not expand
the number of collectors** before proving that result.
