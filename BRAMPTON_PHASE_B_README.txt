BRAMPTON BROADER DEPARTMENTAL COLLECTION - OCTOBER 2026

This is a single integrated expansion, not a replacement of the working Radar modules.

New modules:
- 20 additional public stationary business-licence category pages (category by category).
- 5 public Brampton Roadworks ArcGIS layers; uses official maps1.brampton.ca, not mapsdev.
- Council, planning, licensing, public works, city budget, procurement and economic development PAGE CONTENT and useful linked-document METADATA monitoring.
- Existing permit activity, inspection history, food licence collector continue unchanged.

First-run caution: Each public source will be attempted; a failure is reported per source and never prevents the rest of Radar running. Some official licensing pages may use varying SharePoint column formats or pagination; those collectors honestly report PARTIAL or ERROR. Incomplete sources never trigger deletions. Document monitors are not full PDF indexing and JS-only planning portals aren't bypassed.

DATA PRESERVATION: Continue using your present brampton_sources.sqlite file by COPYING it into this package's data folder before START_RADAR.bat. Never overwrite or delete the source file in your existing installation. For very large historical permit backfills, the saved checkpoint is essential.

The existing radar.sqlite is also preserved. Check data/brampton_collection_report.html after running.

This package passed local/offline tests only; live Brampton source collection remains to be validated in your environment.
