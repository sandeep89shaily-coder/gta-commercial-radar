GTA Commercial Radar - EASY START

1. Extract the ZIP into the same 'new data' folder as your older GTA Radar folders.
2. Open the newly extracted GTA_RADAR_EASY_START folder.
3. Double-click START_RADAR.bat.

What it does:
- Finds the v0.7 database in nearby folders and makes an integrity-checked COPY.
- Never deletes or modifies your earlier Radar installation or database.
- Prepares business discovery, exports fresh lead candidates, then prepares research.
- When a Brave Search API key was already set in Windows, searches up to 10 leads.
- Without a Brave key, prepares the research dashboard but does NOT search the web.
- AI analysis is optional and is not enabled by this easy start button.
- The first data collection is a baseline and may generate zero fresh leads.

Required: Windows, Python 3, internet access for source polling. The launcher installs
Python requirements if missing; these may be downloaded by pip.

Important: This is an easy launcher for v0.12, not a new autonomous search provider.
Actual web investigation still requires a Brave Search API key and permitted access.
The system never approves leads for sale automatically.

If any screen reports 'No fresh candidate leads yet', this is not a setup failure.
Save a screenshot of the final screen to share for troubleshooting.
